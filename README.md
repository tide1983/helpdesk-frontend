HelpDesk — Frontend

[![Deploy to GitHub Pages](https://github.com/tide1983/helpdesk-frontend/actions/workflows/deploy.yml/badge.svg)](https://github.com/tide1983/helpdesk-frontend/actions/workflows/deploy.yml)

Демо: https://tide1983.github.io/helpdesk-frontend/

Frontend для сервиса управления заявками. Собирается через Webpack, деплоится на GitHub Pages через GitHub Actions.

Возможности

- Отображение списка тикетов
- Создание нового тикета
- Редактирование тикета
- Удаление с подтверждением
- Отметка «сделано»
- Просмотр подробного описания

Запуск

```bash
npm install
npm start
